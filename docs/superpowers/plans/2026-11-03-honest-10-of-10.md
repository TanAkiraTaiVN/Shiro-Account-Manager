# Honest 10/10 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the gap between "metric gates pass" and "real quality" left by the 2026-11-02 plan: honest coverage measurement, complete i18n, meaningful localization keys, behavior-level tests, and injected (not ambient) logger/settings in the testable layers.

**Architecture:** Every task adds a guard test to `tests/Shiro.Tests/ArchitectureTests.cs` (or a dedicated test file) first, watches it fail on the current tree, then fixes the tree. Gates are ratchets: baselines are exact numbers that may only decrease. Static `Default` singletons stay as the composition root; services gain constructor-injected `IAppLogger` / `ISettingsService`.

**Tech Stack:** .NET 10, Avalonia, xUnit, NSubstitute 5.3.0, coverlet (XPlat Code Coverage), PowerShell 5.1+ scripts, GitHub Actions.

**Spec:** Findings in the "đã đủ để 10/10 chưa" review (2026-11-03) — summarized here because no separate spec doc exists:
1. Coverage gate inflated by 17 `ExcludeByFile` patterns added in commit `ccb4f6b`.
2. 60 `IsEnglish ? "<english literal>" : Get(...)` branches; `"Xem Ban"` hardcoded (non-diacritic Vietnamese escapes the regex test).
3. 561 `Auto_<Prefix>_<NNN>` keys in `vi.json` (661 usages in C#).
4. `CoreCoverageExpansionTests.cs` (440 lines) mostly sets properties and asserts `NotNull`/`NotEmpty`.
5. 269 `AppSettings.` and 731 `Program.Logger` ambient static references.

## Global Constraints

- `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>`: 0 warnings, 0 errors on `dotnet build`.
- `.cs` ≤ 500 lines; `.axaml` ≤ 400 lines and ≤ 200 chars/line (existing `ArchitectureTests`).
- All 18 existing `ArchitectureTests` keep passing after every task.
- No new `ExcludeByFile` / `Exclude` patterns in `tests/coverage.runsettings` beyond the approved list in Task 1.
- Default UI language stays Vietnamese; `LocalizationService.SetLanguage(..., saveSetting: false)` in tests only.
- Tests that set static seams (`Account.TestHttpClientFactory`, `LocalizationService.CurrentLanguage`) belong to `[Collection("StaticSeams")]` (non-parallel).
- One commit per task, Conventional Commits.

## Review Focus

1. Runtime language toggle: already-constructed view models must re-raise text properties (`NotifyLanguageChanged`) so the visible text flips without restart → test in Task 2.
2. `LocalizationService.Format` with a key whose English value has fewer `{n}` placeholders than args, or a literal `{` → must not throw → test in Task 2.
3. Key rename leaves an AXAML `{DynamicResource Auto_…}` or a string-built key dangling → must be caught at test time, not at runtime → test in Task 3.
4. Static `Account.TestHttpClientFactory` leaking between parallel tests → flaky passes/failures → collection fixture in Task 4.
5. Roblox CSRF flow (403 + `x-csrf-token` header, then retry) is the most common real-world path for every POST → test in Task 4.

public void AccountViewModel_ViewBanButtonText_FollowsLanguageAndRaisesChange()
{

    var raised = new List<string?>();

[Fact]
public void Format_WithMismatchedPlaceholdersOrBraces_DoesNotThrow()
{
    LocalizationService.SetLanguage(AppLanguage.English, saveSetting: false);
    // no args -> template returned unformatted
    Assert.Equal("Player '{0}' was not found in current public servers.", LocalizationService.Format("ServerList.PlayerNotFound"));
    // extra args are ignored by string.Format
    Assert.Equal("Player 'a' was not found in current public servers.", LocalizationService.Format("ServerList.PlayerNotFound", "a", "b"));
    // missing key -> key returned (Get falls back to key)
    Assert.Equal("__missing_key__", LocalizationService.Format("__missing_key__", "x"));
    // template with literal brace and an arg -> SafeFormat must not throw
    var ex = Record.Exception(() => LocalizationService.Format("__missing_key__", "{bad", 1));
    Assert.Null(ex);
}
